# MONETIZATION

**プロダクト**: MusicGrow v5
**ステータス**: 設計フェーズ
**バージョン**: v1
**最終更新**: 2026-05-18

MusicGrow のマネタイズ方針を定義します。コア思想を崩さない範囲で、持続可能な収益構造を設計します。

---

## 1. マネタイズの大原則

### 1.1 MusicGrow コアを崩さない

MusicGrow の核は次の3つです：

- 自己満足したい人が1人でウフッ
- 他人には見せない日記
- 練習した自分と再会する

マネタイズはこの核を**1ミリも崩さない**範囲で設計します。

### 1.2 原則を一行で

> 機能で人質を取らない。価値で選んでもらう。

「無料だと過去のひとことが見られない」は人質を取るマネタイズ。「無料だと製本できない」は価値で選んでもらうマネタイズ。MusicGrow は後者でいきます。

### 1.3 やってはいけないこと

| 禁止事項 | 理由 |
|---|---|
| 広告表示 | 自己満足の世界に他者の声が入る |
| データを売る・解析して第三者提供 | "他人には見せない"が嘘になる |
| SNS共有を促す機能 | "1人でウフッ"を壊す |
| ストリークで課金圧をかける | "休符の日"思想と矛盾 |
| 過去のひとこと閲覧を有料化 | "再会"を人質に取る |
| 派手なバッジ・ランキングの有料化 | "内輪の宝物"思想と矛盾 |
| AI連携を有料化（当面） | 思想との整合性、競合差別化、普及速度（詳細は AI_READINESS.md 第5章） |

---

## 2. 無料で提供し続けるもの（コア機能）

以下はすべて無料です。長く使う人にも、初めて使う人にも、同じ品質で提供します。

### 2.1 基本機能

- 練習タイマー、メトロノーム
- 曲名登録、楽器管理
- カレンダー表示
- 採点モック
- スタンプカード、1000時間トラッキング

### 2.2 「今日のひとこと」関連すべて

- カード表示、自由記述、気分スタンプ、そっとしまう
- 全128個のプレースホルダー（4トーン + 休符の日）
- 過去のひとこと閲覧（無制限）
- 再登場機能
- ふいの再会演出
- 節目演出（100/300/500/1000時間、戻ってきた回数の小さい節目）
- 「あなたの道の言葉」まとめ
- 「内輪の宝物」コレクション
- 休符の日機能
- お気に入り（isFavorite）

### 2.3 AI 連携

- JSON エクスポート機能
- MCP サーバーへの接続
- ユーザー自身の AI（Claude、ChatGPT 等）からの読み取り

詳細は AI_READINESS.md を参照。

### 2.4 データ管理

- データの完全エクスポート
- データの完全削除
- 機種変更時のインポート

## 3. マネタイズの軸

3 つの軸で収益を作ります。

### 軸 A: 装飾・テクスチャ（買い切り）

ユーザー体験の**質感**を有料化。機能ではなく見た目・触感。

### 軸 B: 製本・物理（買い切り）

デジタルデータを物理的な「自分だけの宝物」に変える。

### 軸 C: サポーター制度（任意月額）

「気に入ったら応援」モデル。機能制限なし。

---

## 4. 軸 A: 装飾の詳細

### 4.1 提供内容

| カテゴリ | 例 | 価格帯 |
|---|---|---|
| 紙テクスチャ | 和紙、ヴェラム、生成り、コットン、トレーシングペーパー | 300〜600円/個 |
| 季節テーマ | 春・夏・秋・冬、雨の日、夜空、朝靄 | 500〜800円/個 |
| 節目演出の拡張 | 100時間到達時の追加アニメーション、音 | 800〜1200円 |
| カスタムフォント | 手書き風、明朝、楷書、ペン字 | 300〜500円/個 |
| 装飾セット（バンドル） | 上記の組み合わせパック | 1000〜1500円 |

### 4.2 設計思想

装飾は**買った本人だけがニヤッとする**もの。他人には見えない。

「自己満足の世界で、自分の机の引き出しの中身を、自分の好きな質感に整える」。これは MusicGrow の世界観と完全に一致します。

### 4.3 提供方法

- アプリ内に「装飾ストア」ページを設置
- 各装飾はサムネイルとプレビューで見せる
- 購入は Stripe や App Store 内課金など、業界標準の決済を使う
- 一度買えば永久利用可能

### 4.4 実装難度

中。UI のテーマ切り替え機構と決済連携が必要。

## 5. 軸 B: 製本の詳細

### 5.1 提供内容

| 商品 | 説明 | 価格帯 |
|---|---|---|
| ひとこと製本（1年版） | 1年分のひとことを文庫サイズの本に。表紙はカスタマイズ可 | 1500〜2500円 |
| 節目記念ブック | 100/300/500/1000時間到達時の記念製本 | 2000〜3500円 |
| 「あなたの道の言葉」カードセット | お気に入りのひとことをカードに。30〜50枚 | 1500〜2500円 |
| 大判製本（厚口） | 5年分など、まとめて1冊に | 3500〜5000円 |

### 5.2 設計思想

> デジタルの「再会」を、物理の「再会」へ。

ひとことは本来デジタルですが、本にすると数十年後も読める。MusicGrow の「道」が物理的に手元に残る。これは Day One が製本サービスで成功している領域でもあります。

### 5.3 オペレーション設計

初期投資をゼロに近づけるため、**印刷オンデマンド連携**を使います。

候補：
- しまうまプリント（フォトブック、簡単なオプション）
- TOLOT（高品質、文庫サイズ対応）
- BookOn（製本向け、業務利用しやすい）
- Lulu（海外、英語ユーザー向け）

フロー：
1. ユーザーがアプリ内で「製本する」を選ぶ
2. 期間や対象（曲別など）を指定
3. プレビュー画面で確認
4. 注文確定、決済
5. MusicGrow が印刷オンデマンドサービスに発注
6. 直接ユーザーへ配送

MusicGrow 側の利益は「販売価格 − 印刷代 − 決済手数料」。

### 5.4 在庫リスク

印刷オンデマンドなので**在庫リスクゼロ**。注文が入ってから印刷する。

### 5.5 実装難度

高。製本デザインのテンプレート作成、印刷サービスとの API 連携、決済フロー、配送状況の追跡。

総工数: 1〜2ヶ月（Phase 3 以降に着手）

## 6. 軸 C: サポーター制度の詳細

### 6.1 概要

| 項目 | 内容 |
|---|---|
| 月額 | 500円（または年額5000円） |
| 機能制限 | なし。全機能はサポーターでなくても使える |
| 特典 | サポーターバッジ（本人だけが見える、内輪の宝物） |
| 解約 | いつでも自由、解約後も機能は使える |

### 6.2 設計思想

「無料で使えるけど、MusicGrow が好きだから払う」という形。自己満足の人は払うことすら自己満足になる。

### 6.3 参考事例：Stoic

Stoic という瞑想・ジャーナルアプリは「データを売らない、永久無料」を掲げながら、有料機能で 400 万ユーザーを抱えるビジネスを成立させています。MusicGrow も「プライバシー守りつつ稼ぐ」モデルとして参考になります。

### 6.4 想定収益

| 想定 | サポーター比率 | 月額 | 月収 |
|---|---|---|---|
| ユーザー100人 | 5% | 500円 | 2,500円 |
| ユーザー1,000人 | 3% | 500円 | 15,000円 |
| ユーザー10,000人 | 2% | 500円 | 100,000円 |

サポーターだけで生計を立てるのは難しいですが、他の軸と合わせると意味のある収益になります。

### 6.5 実装難度

中。サブスク決済（Stripe Subscriptions など）の連携、解約管理、バッジ表示。

| 商品 | 価格設定 | 理由 |

| 装飾（バンドル） | 1,000〜1,500円 | お得感を出す |

### 7.3 無料ユーザーと有料ユーザーの想定比率

| ユーザータイプ | 比率 |
|---|---|

| 装飾を1〜2点購入 | 5〜10% |

複数カテゴリにまたがる人もいるので、合計は重複あり。

## 8. ロードマップ

### Phase 1（MVP 〜 半年）：完全無料、信頼を作る

- マネタイズ機能ゼロ
- 機能とコミュニティの土台を作る
- ユーザーの声を集め、何が大事にされているかを把握

判断指標：
- アクティブユーザー数
- 「ひとこと」の累積記入数
- ユーザーからの感想・要望

### Phase 2（ユーザー100人〜）：装飾販売開始

- 装飾ストアをリリース
- 初期は紙テクスチャ3種、季節テーマ2種など、少なめに開始
- 売れ筋を見ながら追加

判断指標：
- 装飾の購入率
- リピート購入の有無
- 装飾追加要望の傾向

### Phase 3（ユーザー1,000人〜）：製本サービス開始

- 印刷オンデマンド連携を構築
- まずは1年版製本のみ
- ユーザー反応を見ながら、記念ブック、カードセットを追加

判断指標：
- 製本注文数
- 配送品質への満足度
- 利益率

### Phase 4（コミュニティ形成後）：サポーター制度開始

- 「MusicGrow を応援する」というメッセージを丁寧に伝える
- 機能制限ゼロを強調
- バッジは控えめに、本人だけが分かる形で

判断指標：
- サポーター転換率
- 解約率
- サポーターからのフィードバック

## 9. 倫理的なコミットメント

MusicGrow がユーザーと結ぶ「信頼の約束」を明文化します。プライバシーポリシーやアプリ内の説明に反映します。

### 9.1 約束すること

| 項目 | 約束 |
|---|---|
| 広告 | 永久に表示しない |
| データ販売 | しない |
| 学習データ提供 | しない |
| コア機能の有料化 | しない（タイマー、ひとこと、カレンダー、エクスポート） |
| サブスクで人質 | 取らない（解約後も既存データは見られる） |
| ダークパターン | 使わない（解約しにくいUI、自動更新の誤誘導など） |

### 9.2 約束しないこと（誠実さのため）

| 項目 | 理由 |
|---|---|
| 「永久無料」全体 | 業界状況の変化に対応できなくなる |
| 「永久にAI連携無料」 | 同上。ただし当面は無料維持 |
| 「すべての追加機能を無料」 | 装飾・製本などは有料 |

### 9.3 変更時のルール

マネタイズ方針を変更する場合：

- 最低3ヶ月前に告知
- 既存ユーザーへの配慮（移行期間中の既存利用は維持）
- なぜ変更が必要かを丁寧に説明
- ユーザーからのフィードバックを受け付ける
