- 第0章「MusicGrowの核となる考え方」を新規追加

## 2. トーンに「探究」を追加（4種類に拡張）

v1 は3トーン（やさしい/淡々/茶目っ気）でしたが、ハマっている人・職人気質・研究メモ的に使いたい人に向けた**第4のトーン「探究」**を追加しました。

| トーン | 想定ユーザー |
|---|---|
| やさしい | めげそうな人を支える |
| 淡々 | 事実を記録したい人 |
| 茶目っ気 | 自己満足や小さな笑いに合う |
| **探究** | ハマっている人、職人気質、研究メモ的に使いたい人（v2追加） |

探究トーンのプレースホルダー30個を新規執筆。観察・身体感覚・他者との比較・時間軸の4領域に配分。

## 3. 「休符の日」機能の追加

練習しなかった日を「失敗」ではなく「休符」として記録する機能を新設。

> 練習しない日も、音楽をやめた日ではない。

- ホーム画面に「休符の日として残す」ボタン
- 専用カード、`sessionType: "rest"` で保存
- 専用プレースホルダー8個を執筆
- カレンダーには小さな休符マークで表示

これは他の練習アプリにない MusicGrow 独自の発明。「練習できなかった日が続いた時にめげる」という、音楽趣味で最大のリスクへの受け皿。

## 4. 節目の再設計

v1: 100時間 / 300時間 / 500時間 / 1000時間
v2: 上記に加え、**100時間より前の小さな節目を多数追加**

| 節目 | 表示文案 |
|---|---|
| 3回（戻ってきた回数） | また戻ってきた |
| 7回 | もう少し生活に入ってきた |
| 10回 | 小さな道ができてきた |
| 30回 | これは、続いていると言っていい |
| 10時間 | 音と過ごした時間が形になってきた |
| 30時間 | 前の自分とは、少し違う |
| 100時間 | ここまで来てた |
| 300時間 | あなたの道が形になってきた |
| 500時間 | 半分まで来た、というより、ここまで来た |
| 1000時間 | 道になった |

「**戻ってきた回数**」軸を新設。毎日続ける人だけでなく、空けても戻ってくる人を祝う思想。

## 5. 再登場機能を MVP に格上げ

v1 では Phase 3（後で）の機能でしたが、v2 では**一部を MVP に格上げ**。

MVP に入れる：
- タイマー開始前のローディング画面に「前回のあなたはこう書いていました」を表示
- 同じ曲を開いたときに、前回のひとことを表示

理由：MusicGrow の核は「再会」。再登場機能を後回しにすると、他の練習アプリと区別しづらくなる。

## 7. データ構造の拡張

v1 のJSON構造に4項目を追加。

| 追加項目 | 目的 |
|---|---|
| `promptId` | 表示されたプレースホルダーID。将来「どの問いがよく書かれるか」を分析できる |
| `tone` | 表示されたトーン。後から見返したときの空気感を残せる |
| `sessionType` | practice / rest / recording / score_reading / listening / lesson |
| `isFavorite` | 自分だけの宝物として保存。「お気に入りのひとこと」「道の言葉」で使える |

また、`instrumentId` も明示的に項目化（v1 では暗黙的）。

## 8. 保存方針とプライバシーの明文化

v2 で第16章として新規追加。

ひとことはかなり個人的な内容（しんどかった、人間関係、家族の話など）になる可能性があるため、保存方針を慎重に設計。

| 方針 | 内容 |
|---|---|
| 基本は端末内保存 | サーバーに自動送信しない |
| エクスポートはユーザー操作 | 自分で明示的にダウンロード |
| クラウド同期は明示同意 | デフォルトオフ |
| GitHub保存は開発者向け | 一般機能としては露出させない |

> いきなりクラウドに上がるより、自分の机の引き出しにしまう感じ。

v1 では「localStorage / GitHub への保存」と並記してましたが、これは誤解を招くため修正。

## 10. プレースホルダー文の修正（強すぎる表現の見直し）

「他人には見せない日記」の思想と合わない表現を修正。

| ID | 元の文 | 修正後 |
|---|---|---|
| p_j_05 | 今日の自分、何点あげる？甘めで | 今日の自分に、何をあげたい？ |
| p_j_10 | 作曲者に見られたら怒られそうな箇所 | 作曲者に小声で謝りたい箇所 |
| p_j_23 | 先生に怒られそうな、今日のサボりポイント | 今日のサボりポイント、弁明をどうぞ |
| p_p_29 | この曲、いまの自分にとって何点くらい | この曲との距離、少し近づいた？ |

修正理由：
- 「点数化」は「数字より物語」の思想と合わない
- 「先生に怒られる」「作曲者に怒られる」は権威への恐怖を刺激しすぎる
