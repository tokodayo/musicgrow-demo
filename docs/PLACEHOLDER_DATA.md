# プレースホルダー文 データ台帳

**機能**: 今日のひとこと
**バージョン**: v2
**最終更新**: 2026-05-18

中立語版プレースホルダーの台帳。将来 JSON 化する前提のマークダウン形式。

---

## 構造

各文はID付き。IDは `p_{tone}_{seq}` 形式。

- `p_g_01` 〜 `p_g_30`: やさしい（gentle）
- `p_p_01` 〜 `p_p_30`: 淡々（plain）
- `p_j_01` 〜 `p_j_30`: 茶目っ気（joke）
- `p_o_01` 〜 `p_o_30`: 探究（observe） ← v2追加
- `p_rest_01` 〜 `p_rest_08`: 休符の日 ← v2追加

## 出現アルゴリズム（暫定仕様）

```
1. ユーザーのトーン設定を取得（やさしい/淡々/茶目っ気/探究/おまかせ）
   - 「おまかせ」なら、その日の日付から決定論的にトーンを選ぶ
     （同日中に複数回タイマー停止しても同じトーンが出る）

2. 候補プールを作成
   - 中立版30個（選択されたトーン）
   - Tier 1楽器の場合: 楽器専用文も追加
   - 譜面記号が設定されていれば: 該当する譜面記号依存文も追加
   - 曲名が登録されていれば: 確率20%で dynamic 文を追加

3. 直近3回で表示した文を除外（連続表示防止）

4. プールからランダムに1つ選択

5. 表示

なお、休符の日（sessionType: "rest"）の場合は、4トーンとは別の rest 専用プールから選ぶ。
```
