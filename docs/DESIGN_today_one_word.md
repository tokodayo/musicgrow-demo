## 0. はじめに：MusicGrow の核となる考え方

MusicGrow は、練習を管理するアプリではありません。**音楽と過ごした時間を、自分だけの道として残すアプリ**です。

特に「今日のひとこと」は、ただの日記機能ではなく、練習後に自分の言葉をそっと残し、あとで過去の自分と再会するための機能です。

> 練習したかどうかを管理するアプリではなく、練習した自分と、あとで再会するアプリ。

既存の音楽練習アプリは、タイマー・メトロノーム・録音・練習ログ・ストリーク・ノートなどの「練習管理」寄りが中心です。MusicGrowはそこではなく、次を差別化の軸にします。

> 練習を効率化するより、練習を自分の物語にする。

---

## 1. 「今日のひとこと」の心理的な役割

音楽を趣味で続ける人にとって大事なのは、単なる上達ではありません。続けるためには、次の3つが大切です。

- 自分で選んでいる感覚（自律性）
- 少しできるようになっている感覚（有能感）
- 誰か、または過去の自分とつながっている感覚（関係性）

| 心理的支え | MusicGrowでの対応 |
|---|---|
| 自律性 | 書いても書かなくてもいい、トーン選択、SNS共有なし |
| 有能感 | 小さな節目、過去の言葉、曲との距離感 |
| 関係性 | 他人ではなく、過去の自分との再会 |

特に「**他人には見せない**」は重要です。音楽趣味は、誰かに見せた瞬間に評価が入ります。それによって自己満足の世界が壊れる人もいます。MusicGrowはSNS共有を前提にせず、あくまで「自分だけがニヤッとできる」世界を守ります。

---

## 2. コンセプト

タイマー停止後、画面下から白いカードがふわっと現れる。今日の練習について、一言だけ書ける。書かなくてもいい。「そっとしまう」ボタンで閉じる。それだけ。

数字（時間・採点）の世界から、言葉（気分・気づき・ぼやき）の世界へ橋を渡す機能。

### 設計思想の三原則

1. **押し付けない** スキップ自由、書かなくてもいい、出さない設定もできる
2. **他人には見せない** SNS連携なし、共有機能なし、徹底的に個人の日記
3. **ふいに再会する** 過去のひとことが、忘れた頃に顔を出す

---

## 3. 起動タイミングと出現演出

タイマー停止 → 結果サマリ表示 → カードがふわっとせり上がる。

- **表示条件**: 練習時間が3秒以上（誤タップ除外）
- **閉じ方**: 「そっとしまう」ボタン、または下方向スワイプ
- **スキップ**: 何も書かずに閉じても完全OK
- **設定**: ユーザー側で自動表示オフにできる（設定画面）

---

## 4. カード構成要素

上から順に：

1. **日付＋曲名**（あれば）薄いグレー、小さく
2. **気分スタンプ** 🙂😊🤩😌🥲 横並び、1つだけ選択可（再タップで解除）
3. **自由記述欄** プレースホルダーにヒント文ランダム表示
4. **「そっとしまう」ボタン** 書かなくても押せる

スタンプも文章も任意。両方空でも閉じられる。

## 5. データ構造

### ひとこと1件

```json
{
  "id": "uuid",
  "date": "2026-05-18",
  "createdAt": "2026-05-18T20:34:12+09:00",
  "pieceId": "chopin-op10-3",
  "instrumentId": "piano",
  "practiceMinutes": 27,
  "mood": "😊",
  "text": "今日は左手が歌えた気がする",
  "promptId": "p_g_12",
  "tone": "gentle",
  "sessionType": "practice",
  "tags": ["left_hand", "tone"],
  "isFavorite": false,
  "reappearedCount": 0,
  "lastReappearedAt": null
}
```

### 各項目の役割

| 項目 | 目的 |
|---|---|
| `pieceId` | 曲との紐付け。曲ごとの「会話」表示に使う |
| `instrumentId` | 楽器ごとの分析・出し分けに使う |
| `practiceMinutes` | その日の練習時間。0なら「休符の日」 |
| `mood` | 気分スタンプ。null可 |
| `text` | 自由記述。空可 |
| `promptId` | 表示されたプレースホルダーID。将来分析用 |
| `tone` | 表示されたトーン |
| `sessionType` | `practice` / `rest` / `recording` / `score_reading` / `listening` / `lesson` |
| `tags` | 自動抽出または手動付与のタグ |
| `isFavorite` | お気に入り。「道の言葉」で使う |
| `reappearedCount` | 再登場回数。多いほど次の登場確率を下げる |
| `lastReappearedAt` | 最後に再登場した日時 |

## 6. プレースホルダー文の設計

### 6.1 トーン（4種類）

オンボーディング時に1つ選び、設定画面でいつでも変更可能。

| トーン | 性格 | 想定ユーザー | サンプル |
|---|---|---|---|
| **やさしい** | 寄り添う、温度のある声 | めげそうな人を支える | 今日の手元、どんな表情をしてた？ |
| **淡々** | 事実を置く、メモのような距離感 | 事実を記録したい人 | 今日の練習について、ひとこと残す |
| **茶目っ気** | 自分にツッコむ、軽口 | 自己満足や小さな笑いに合う | 今日いちばん「えっ今の何!?」だった瞬間 |
| **探究** | 観察と研究のまなざし | ハマっている人、職人気質、研究メモ的に使いたい人 | うまくいった瞬間の条件を、ひとつ残す |

### 6.2 「探究」トーンの追加意義

ある程度ハマっている人は、慰めよりも自分の感覚を精密に保存したい。練習を「努力」ではなく「観察」として楽しむ。このトーンは初心者向けではなく、長く使う人に効く。

### 6.3 「日によって変える」モード

トグルをオンにすると、毎日ランダムでトーンが変わる。開くまでどのトーンか分からない。占いみたいな楽しみ方。"自分でコントロールしない＝道に身を任せる"感じが効く。

同じ日に複数回タイマー停止しても、同じトーンが出るよう日付ベースで決定論的に選択。

### 6.4 主語・語り口

「他人には見せない日記」のトーンで統一。主語は省略多め。問いかけ調と独白調の混在。

### 6.5 文の長さ

20〜30文字を基準。短すぎず、長すぎず。

### 6.6 プレースホルダー総数

| カテゴリ | 個数 |
|---|---|
| やさしい（中立版） | 30 |
| 淡々（中立版） | 30 |
| 茶目っ気（中立版） | 30 |
| 探究（中立版） | 30 |
| 休符の日 | 8 |
| **合計** | **128** |

詳細は [PLACEHOLDER_DATA.md](./PLACEHOLDER_DATA.md) を参照。

## 7. 楽器対応戦略

### 7.1 競合との差別化

主要競合（Modacity, Andante, Instrumentive, Athenify, tuneUPGRADE等）は「対応楽器リスト」で勝負しているが、**「楽器ごとに体験が違う」アプリは存在しない**。

MusicGrowは「広く浅く対応」ではなく「主要楽器を深く対応＋その他は中立語で」の戦略を取る。

### 7.2 Tier分け

| Tier | 楽器 | 対応内容 |
|---|---|---|
| **Tier 1** | ピアノ、ギター、ヴァイオリン、歌（ボーカル） | 中立版＋楽器専用文10〜15個／トーン |
| **Tier 2** | ベース、ドラム、フルート、サックス、ウクレレ、チェロ | 中立版のみ |
| **Tier 3** | その他（自由入力含む） | 中立版のみ |

### 7.3 Tier 1 専用文の役割

中立版を**置き換える**のではなく、中立版に**追加する**もの。出現比率は 中立:専用 = 2:1 〜 3:1。

専用文が果たす3つの価値：

1. **楽器の手触りがある文** 「鍵盤」「弓」「弦」などの語が、奏者の身体記憶を呼び起こす
2. **その楽器ならではの悩み・喜び** ピアノの両手独立、ヴァイオリンの松脂、ボーカルののど
3. **コミュニティの内輪語** アンブシュア、ボウイング、ハイポジなど

### 7.4 中立化の執筆原則

**避ける語**: 指、手、左手、右手、弓、鍵盤、弦、ピック、スティック、リード、ペダル、弾く、叩く、吹く、押さえる、喉、ト音、ヘ音、TAB

**使う語**: 楽器、手元、音、鳴らす、奏でる、向き合う、触れる、身体、ひと節、ところ

### 8.1 対応する記号

| 記号 | 主な使用楽器 |
|---|---|
| ト音記号 | ピアノ右手、ヴァイオリン、ギター、フルート、サックス、トランペット、声楽（高音域） |
| ヘ音記号 | ピアノ左手、ベース、チェロ、コントラバス、トロンボーン、ファゴット |
| ハ音記号・アルト | ヴィオラ |
| ハ音記号・テノール | チェロ高音域、トロンボーン高音域、ファゴット高音域 |
| TAB譜 | ギター、ベース、ウクレレ |
| 打楽器譜表 | ドラム、パーカッション |

### 8.2 オンボーディング

楽器を選んだ瞬間に譜面記号を**自動推定セット**。一般的でない人だけ「変更する」ボタンで修正。

「どれもしっくりこない（記号を意識しない）」選択肢を用意。耳コピ派・即興派・記号を読まない奏者への配慮。記号関連の文を出さないモードになる。

## 10. カレンダー・曲目管理との紐付け

### 10.1 カレンダー

- ひとことがある日は、日付の下にmood絵文字（なければグレードット）を表示

### 10.2 曲目管理

各曲の詳細ページに「**この曲との会話**」セクション。
紐付いたひとことを時系列タイムラインで表示。
mood絵文字＋日付付き。お気に入り（isFavorite）はピン留め表示。

## 11. ふいに再登場する仕掛け

### 11.1 なぜMVPに入れるか

MusicGrowの核は「**練習した自分と、あとで再会する**」こと。再登場機能を後回しにすると、MusicGrowが他の練習アプリと区別しづらくなる。最小実装でいいので、MVPに含める。

### 11.2 発火タイミング

| タイミング | 表示内容 | 優先度 |
|---|---|---|
| **タイマー開始前のローディング画面** | 「前回のあなたはこう書いていました」を薄く表示 | **MVP** |
| **同じ曲を開いたとき** | 「前にこの曲のとき、こう書いてました」 | **MVP** |
| 練習を5日以上空けて再開 | 「最後にあなたが残した言葉」 | 早め |
| カレンダーの「今日」セル長押し | 過去の同じ月日のひとこと | 後で |
| 3ヶ月前/半年前のランダム表示 | 「3ヶ月前のあなたはこう言ってました」 | 後で |

### 11.3 出現確率の制御

- 毎回出ない（控えめに）
- `reappearedCount` が増えるほど次の登場確率を下げる → まんべんなく古いひとことが顔を出す
- 設定でオン/オフ、頻度（控えめ/普通）

> 「練習しなさい」ではなく、「前の自分が待っている」感じになる。

## 12. 「休符の日」機能

### 12.1 趣旨

音楽趣味で一番めげるのは、練習した日ではなく、**練習できなかった日が続いた時**。今の設計では、タイマー停止後にひとことが出るため、練習できなかった日は何も残らない。

「休符の日」は、練習しない日も「失敗」ではなく「休符」として扱うための受け皿。

> 練習しない日も、音楽をやめた日ではない。

### 12.2 機能仕様

- ホーム画面に「休符の日として残す」ボタン
- タップすると専用カードが出る（タイマー停止後のカードと同じ構造）
- `sessionType: "rest"` で保存
- `practiceMinutes: 0`
- 気分スタンプと自由記述、両方任意

### 12.3 専用プレースホルダー

8個用意。詳細は [PLACEHOLDER_DATA.md](./PLACEHOLDER_DATA.md) の「休符の日」セクション。

### 12.4 カレンダー表示

- 休符の日には小さな休符マーク（𝄽 など）
- 連続表示でも責めない、淡々と並ぶ
- 練習日と休符日が混在しても、「道」として見える設計

## 13. 節目と「あなたの道の言葉」

### 13.1 節目の設計

100時間より前に、**小さな節目**を多く配置する。初心者・再開勢への配慮。

> 毎日練習する人だけが偉いのではなく、空いても戻ってくる人が強い。

| 節目 | 表示文案 |
|---|---|
| 3回 | また戻ってきた |
| 7回 | もう少し生活に入ってきた |
| 10回 | 小さな道ができてきた |
| 30回 | これは、続いていると言っていい |
| 10時間 | 音と過ごした時間が形になってきた |
| 30時間 | 前の自分とは、少し違う |
| 100時間 | ここまで来てた |
| 300時間 | あなたの道が形になってきた |
| 500時間 | 半分まで来た、というより、ここまで来た |
| 1000時間 | 道になった |

「**戻ってきた回数**」と「**累積時間**」の二軸で節目を持つ。

### 13.2 大きな節目（100/300/500/1000時間）の表示

全画面モーダル。
タイトル：「あなたがここまで歩んだ道で、残してきた言葉たち」
内容：その期間のひとことを時系列で並べる。

### 13.3 節目ごとのトーン

| 節目 | トーン |
|---|---|
| 100時間 | 素朴な驚き |
| 300時間 | 少し誇らしげ |
| 500時間 | しみじみ |
| 1000時間 | 言葉少なめ |

### 13.4 共有機能

スクショして保存できる（自己満足ポイント）。SNS連携は明示的にしない。

## 14. 「内輪の宝物」コレクション

ランキングや派手なバッジは MusicGrow に合わない。称号より「**言葉のコレクション**」。

| 条件 | 表示 |
|---|---|
| 同じ曲を10回練習 | この曲との会話が増えてきた |
| 3回連続で同じ箇所を書いた | ここ、ずっと気になってるみたい |
| 1か月前と同じ曲 | この曲、まだあなたの中にいる |
| 休符の日から復帰 | 戻ってきた音 |
| 初めて録音メモを残した | 今日の音を保存した |

他人に見せるためのバッジではなく、自分だけが分かる小さな宝物。

## 16. 保存方針とプライバシー

ひとことはかなり個人的な内容になる可能性がある（しんどかった、人間関係、家族の話など）。保存方針は慎重に。

### 16.1 基本方針

| 方針 | 内容 |
|---|---|
| **基本は端末内保存** | localStorageまたは端末DB。サーバーに自動送信しない |
| **エクスポートはユーザー操作** | 自分で明示的にダウンロード操作 |
| **クラウド同期は明示同意** | デフォルトオフ、説明を読んだ上で同意 |
| **GitHub保存は開発者向け** | 一般ユーザー向け機能としては露出させない |

### 16.2 思想

> MusicGrowの世界観的にも、いきなりクラウドに上がるより、自分の机の引き出しにしまう感じの方が合う。

## 17. 実装フェーズ

### 17.1 MVP（絶対入れたい）

これがないと MusicGrow にならないもの。

- 練習タイマー
- 曲名登録
- 気分スタンプ
- 今日のひとこと（カード表示・自由記述・そっとしまう）
- 中立版プレースホルダー（4トーン）
- カレンダー表示
- 過去のひとこと閲覧
- **最後のひとことを練習開始前に再表示**
- **同じ曲を開いたときに、前回のひとことを再表示**
- 端末内保存

### 17.2 早めに入れたい

「再会できるアプリ」をより強くするもの。

- 休符の日機能
- お気に入りのひとこと（isFavorite）
- 曲ごとの「この曲との会話」セクション

- 「内輪の宝物」コレクション
- データエクスポート

### 17.3 後でよい

機能の深さや演出を増やすもの。

- 楽器ごとの深い文言（Tier 1の専用文）
- 譜面記号依存文
- 100 / 300 / 500 / 1000時間の大演出
- スクショ保存機能
- 過去の同月日表示（長押し）
- 共鳴型フィード（最後の最後）

## 18. 競合調査の要旨

| アプリ | 楽器対応 | 特徴 |
|---|---|---|
| Modacity | 約25種類 | 業界最大手、教師連携、楽器ごとの体験差なし |
| Andante | 自由入力＋複数プロフィール | ヴァイオリニスト製、可愛い系UI |
| Instrumentive | 自由入力 | 録音・ノート中心 |
| Athenify | 自由入力 | 株価メタファー、ゲーミフィケーション |
| tuneUPGRADE | 自由入力 | Theory Map、リフレクション重視 |

どのアプリも「楽器選択」はあるが、選んだ楽器によって**文言や体験が変わるアプリはない**。MusicGrowはここで差別化する。

加えて、**「練習しなかった日」を受け止めるアプリも存在しない**。休符の日機能は、MusicGrow独自の発明。
