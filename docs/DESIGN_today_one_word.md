# 今日のひとこと 機能設計書

**プロダクト**: MusicGrow v5
**機能名**: 今日のひとこと
**ステータス**: 設計フェーズ
**最終更新**: 2026-05-18

---

## 1. コンセプト

タイマー停止後、画面下から白いカードがふわっと現れる。今日の練習について、一言だけ書ける。書かなくてもいい。「そっとしまう」ボタンで閉じる。それだけ。

数字（時間・採点）の世界から、言葉（気分・気づき・ぼやき）の世界へ橋を渡す機能。MusicGrowのコアコンセプト「自己満足したい人が1人でウフッて笑顔になる／道を歩む／数字より物語」を体現する中核機能。

### 設計思想の三原則

1. **押し付けない** スキップ自由、書かなくてもいい、出さない設定もできる
2. **他人には見せない** SNS連携なし、共有機能なし、徹底的に個人の日記
3. **ふいに再会する** 過去のひとことが、忘れた頃に顔を出す

---

## 2. 起動タイミングと出現演出

タイマー停止 → 結果サマリ表示 → カードがふわっとせり上がる。

- **表示条件**: 練習時間が3秒以上（誤タップ除外）
- **閉じ方**: 「そっとしまう」ボタン、または下方向スワイプ
- **スキップ**: 何も書かずに閉じても完全OK
- **設定**: ユーザー側で自動表示オフにできる（設定画面）

---

## 3. カード構成要素

上から順に：

1. **日付＋曲名**（あれば）薄いグレー、小さく
2. **気分スタンプ** 🙂😊🤩😌🥲 横並び、1つだけ選択可（再タップで解除）
3. **自由記述欄** プレースホルダーにヒント文ランダム表示
4. **「そっとしまう」ボタン** 書かなくても押せる

スタンプも文章も任意。両方空でも閉じられる。

## 5. プレースホルダー文の設計

### 5.1 トーン

3トーン用意。オンボーディング時に1つ選び、設定画面でいつでも変更可能。

| トーン | 性格 | サンプル |
|---|---|---|
| やさしい | 寄り添う、温度のある声 | 今日の手元、どんな表情をしてた？ |
| 淡々 | 事実を置く、メモのような距離感 | 今日の練習について、ひとこと残す |
| 茶目っ気 | 自分にツッコむ、軽口 | 今日いちばん「えっ今の何!?」だった瞬間 |

**「日によって変える」トグル**: オンにすると毎日ランダムでトーンが変わる。開くまでどのトーンか分からない。占いみたいな楽しみ方。コンセプト的にも"自分でコントロールしない＝道に身を任せる"感じが効く。

### 5.2 主語・語り口

「他人には見せない日記」のトーンで統一。主語は省略多め。問いかけ調と独白調の混在。

### 5.3 文の長さ

20〜30文字を基準。短すぎず、長すぎず。

### 5.4 各トーン30個 × 3トーン = 90個（中立版）

[詳細は PLACEHOLDER_DATA.md を参照]

## 6. 楽器対応戦略

### 6.1 競合との差別化

主要競合（Modacity, Andante, Instrumentive, Athenify, tuneUPGRADE等）は「対応楽器リスト」で勝負しているが、**「楽器ごとに体験が違う」アプリは存在しない**。

MusicGrowは「広く浅く対応」ではなく「主要楽器を深く対応＋その他は中立語で」の戦略を取る。

### 6.2 Tier分け

| Tier | 楽器 | 対応内容 |
|---|---|---|
| **Tier 1** | ピアノ、ギター、ヴァイオリン、歌（ボーカル） | 中立版30個＋楽器専用文10〜15個／トーン |
| **Tier 2** | ベース、ドラム、フルート、サックス、ウクレレ、チェロ | 中立版30個のみ |
| **Tier 3** | その他（自由入力含む） | 中立版30個のみ |

### 6.3 Tier 1 専用文の役割

中立版を**置き換える**のではなく、中立版に**追加する**もの。出現比率は 中立:専用 = 2:1 〜 3:1。

専用文が果たす3つの価値：

1. **楽器の手触りがある文** 「鍵盤」「弓」「弦」などの語が、奏者の身体記憶を呼び起こす
2. **その楽器ならではの悩み・喜び** ピアノの両手独立、ヴァイオリンの松脂、ボーカルののど
3. **コミュニティの内輪語** アンブシュア、ボウイング、ハイポジなど

### 6.4 中立化の執筆原則

**避ける語**: 指、手、左手、右手、弓、鍵盤、弦、ピック、スティック、リード、ペダル、弾く、叩く、吹く、押さえる、喉、ト音、ヘ音、TAB

**使う語**: 楽器、手元、音、鳴らす、奏でる、向き合う、触れる、身体、ひと節、ところ

## 7. 譜面記号の扱い

### 7.1 対応する記号

| 記号 | 主な使用楽器 |
|---|---|
| ト音記号 𝄞 | ピアノ右手、ヴァイオリン、ギター、フルート、サックス、トランペット、声楽（高音域） |
| ヘ音記号 𝄢 | ピアノ左手、ベース、チェロ、コントラバス、トロンボーン、ファゴット |
| ハ音記号・アルト 𝄡 | ヴィオラ |
| ハ音記号・テノール 𝄡 | チェロ高音域、トロンボーン高音域、ファゴット高音域 |
| TAB譜 | ギター、ベース、ウクレレ |
| 打楽器譜表 | ドラム、パーカッション |

### 7.2 オンボーディング

楽器を選んだ瞬間に譜面記号を**自動推定セット**。一般的でない人だけ「変更する」ボタンで修正。

「どれもしっくりこない（記号を意識しない）」選択肢を用意。耳コピ派・即興派・記号を読まない奏者への配慮。記号関連の文を出さないモードになる。

### 7.3 譜面記号依存文

茶目っ気トーンに多めに配置（10個程度）。例：

```json
{
  "id": "p_clef_001",
  "tone": "playful",
  "type": "clef_specific",
  "variants_by_clef": {
    "treble": "ト音記号の上のほう、今日は強気だった？",
    "bass": "ヘ音記号の下のほう、ちゃんと響いてた？",
    "alto": "アルト譜のあのへん、今日も難敵？",
    "tab": "ハイポジション、今日は仲良し？",
    "percussion": "ハイハットとキック、今日のバランスは？",
    "none": null
  }
}
```

`none` の場合は出力しない。

### 8.2 譜面記号確認

楽器を選ぶと自動でセット済み。

```
ピアノを選んだあなたの譜面：
✓ ト音記号 と ヘ音記号
（変更する → ）
```

変更画面：

```
あなたが普段読む譜面はどれ？（複数選んでOK）
□ ト音記号 𝄞
□ ヘ音記号 𝄢
□ ハ音記号（アルト）𝄡 ヴィオラなど
□ ハ音記号（テノール）𝄡 チェロ高音域など
□ TAB譜
□ 打楽器譜表
□ どれもしっくりこない（記号を意識しない）
```

### 8.3 トーン選択

サンプル文を見せて選ぶ。

```
今日のひとこと、どんな声で話しかけてほしい？

○ やさしい
  「今日の手元、どんな表情をしてた？」

○ 淡々
  「今日の練習について、ひとこと残す」

○ 茶目っ気
  「今日いちばん『えっ今の何!?』だった瞬間」

□ 日によって変える（おまかせ）
```

## 9. カレンダー・曲目管理との紐付け

### 9.1 カレンダー

- ひとことがある日は、日付の下にmood絵文字（なければグレードット）を表示
- 日付タップで詳細画面、ひとこと本文も表示
- 「今日」セル長押しで、過去の同じ月日のひとことが出る（ふいの再会）

### 9.2 曲目管理

各曲の詳細ページに「この曲との会話」セクション。
紐付いたひとことを時系列タイムラインで表示。
mood絵文字＋日付付き。

## 10. ふいに再登場する仕掛け

### 10.1 発火タイミング

| タイミング | 表示内容 |
|---|---|
| タイマー開始前のローディング画面 | 「3ヶ月前のあなたはこう言ってました」を2秒間、薄く表示。タップで全文 |
| 同じ曲を弾き始めたとき | 「前にこの曲のとき、こう書いてました」 |
| 練習を5日以上空けて再開 | 「最後にあなたが残した言葉」 |
| カレンダーの「今日」セル長押し | 過去の同じ月日のひとこと |

### 10.2 出現確率の制御

- 毎回出ない（控えめに）
- `reappearedCount` が増えるほど次の登場確率を下げる
- → まんべんなく古いひとことが顔を出す
- 設定でオン/オフ、頻度（控えめ/普通）

## 11. 節目の「あなたの道の言葉」まとめ

### 11.1 発火条件

- スタンプカード達成
- **100時間 / 300時間 / 500時間 / 1000時間** 到達
- 曲の完成宣言

### 11.2 表示

全画面モーダル。
タイトル：「あなたがここまで歩んだ道で、残してきた言葉たち」
内容：その期間のひとことを時系列で並べる。mood絵文字＋日付付き。

### 11.3 節目ごとのトーン

| 節目 | トーン | 締めの一文（案） |
|---|---|---|
| 100時間 | 素朴な驚き | ここまで来てた |
| 300時間 | 少し誇らしげ | あなたの道が形になってきた |
| 500時間 | しみじみ | 半分まで来た、というより、ここまで来た |
| 1000時間 | 言葉少なめ | 道になった |

### 11.4 共有機能

スクショして保存できる（自己満足ポイント）。SNS連携は明示的にしない。

## 14. 競合調査の要旨

| アプリ | 楽器対応 | 特徴 |
|---|---|---|
| Modacity | 約25種類 | 業界最大手、教師連携、楽器ごとの体験差なし |
| Andante | 自由入力＋複数プロフィール | ヴァイオリニスト製、可愛い系UI |
| Instrumentive | 自由入力 | 録音・ノート中心 |
| Athenify | 自由入力 | 株価メタファー、ゲーミフィケーション |
| tuneUPGRADE | 自由入力 | Theory Map、リフレクション重視 |

どのアプリも「楽器選択」はあるが、選んだ楽器によって**文言や体験が変わるアプリはない**。MusicGrowはここで差別化する。

# MusicGrow v5 - 「今日のひとこと」機能 設計ドキュメント

このディレクトリは MusicGrow v5 の次期実装機能「今日のひとこと」の設計ドキュメント群です。

## ファイル構成

| ファイル | 内容 |
|---|---|
| [DESIGN_today_one_word.md](./DESIGN_today_one_word.md) | 機能の全体設計書（コンセプト、データ構造、フロー、楽器対応戦略、実装フェーズ） |
| [PLACEHOLDER_DATA.md](./PLACEHOLDER_DATA.md) | プレースホルダー文の台帳（中立版90文、トーン別） |

## 機能の一行サマリ

タイマー停止後、画面下からふわっと現れる白いカードに、今日の練習について一言だけ書ける。書かなくてもいい。「そっとしまう」で閉じる。過去のひとことは、忘れた頃にふいに顔を出し、節目には「あなたの道の言葉」としてまとめて現れる。

## 設計の核となる決定事項

1. **3トーン切替**（やさしい／淡々／茶目っ気）＋「日によって変える」モード
2. **楽器Tier分け**: Tier 1は4楽器（ピアノ・ギター・ヴァイオリン・歌）で深く対応、その他は中立語で
3. **中立語ファースト**: まず90文の中立版を整備し、Tier 1は追加で楽器専用文を載せる
4. **「他人には見せない日記」**: SNS共有なし、独白に徹する
5. **スタンプカード節目**: 100時間 / 300時間 / 500時間 / 1000時間（前半短く後半長い設計）

## 実装フェーズ

- **Phase 1 (MVP)**: 中立版プレースホルダー、カード表示、保存、紐付け
- **Phase 2**: 楽器対応、Tier 1専用文
- **Phase 3**: ふいの再登場、節目のまとめ表示
- **Phase 4 以降**: 道の演出強化、共鳴型フィード
